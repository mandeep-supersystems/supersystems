Inventory

/inventory
Live
Live
✅
Stock Check-In (GR)
Records goods receipt. Required: po_no, part_or_rm_code, received_qty. Auto: iqc_status = pending_iqc, QR code. Table: inventory_stock_checkins.
POST /api/v1/inventory/checkins
Live
📊
Stock Levels
Live stock per part+warehouse+bin. Updated ONLY after IQC passes. Fields: qty_on_hand, qty_reserved, qty_available. Table: inventory_stock_levels.
GET /api/v1/inventory/stock-levels
Live
🔄
Stock Movements
All movements: RECEIPT, ISSUE, TRANSFER, ADJUSTMENT, RETURN. Each has movement_no, from/to bin, reference_no. Table: inventory_stock_movements.
GET /api/v1/inventory/stock-movements
Live
🔀
Transfers
Move between bins/warehouses. Source decremented, target incremented. TRF- movement created.
POST /api/v1/inventory/transfers
Live
⚖️
Adjustments & Counts
Positive/negative qty adjustments with reason + approver. Cycle count sheets auto-generated from stock. ADJ- / CNT- numbers.
POST /api/v1/inventory/adjustments
Live
🏷
Batch & Serial Tracking
Batch: lot, mfg date, expiry, qty_remaining. Serial: serial_no per item, production_order link. Tables: inventory_batches, inventory_serial_numbers.
GET /api/v1/inventory/batches, /serials
Live
🔔
Reorder Rules & Alerts
Per part: reorder_point, reorder_qty, preferred_supplier. Alert API returns parts where qty_available ≤ reorder_point.
GET /api/v1/inventory/reorder-alerts

📍

Quality Mgmt

/quality
Live
Live
📋
IQC Queue
Reads inventory_stock_checkins WHERE iqc_status='pending_iqc'. Inspector picks a batch to inspect. Shows checkin_no, po_no, supplier, received_qty.
GET /api/v1/quality/iqc → quality.html
Live
🔭
IQC Detail & Inspect
Opens checkin. Auto-loads criteria from quality_iqc_criteria by part code. Inspector enters passed/rejected/scrap qty + remarks. Status set: passed / partial_pass / rejected.
GET+POST /api/v1/quality/iqc/<cid>
Live
📐
IQC Criteria Master
Admin defines inspection parameters per part_or_rm_code: criterion name, spec target, tolerance min/max, inspection method, mandatory flag. Table: quality_iqc_criteria.
POST /api/v1/quality/criteria
Live
⚠️
Non-Conformance (NCR)
Auto-created when rejected_qty > 0. Fields: NCR-no, defect_type, severity=Major, corrective_action, disposition=RTV. Table: quality_ncrs.
auto → quality_ncrs on rejection
Live
📦
GRN-IQC Inspection
Alternative IQC flow via procurement.grn. Inspector accepts/rejects GRN items. Creates quality.iqc_inspections record and updates GRN status to iqc_passed/iqc_rejected.
POST /api/v1/quality/grn-iqc/<grn_id>/inspect
Live
📊
Quality Overview
KPIs: pending_iqc count, passed count, total NCRs, active criteria count.
GET /api/v1/quality/overview-stats
↓ IQC PASS → inventory_stock_levels.qty_on_hand += passed_qty (stock goes live)
⚙️
